## Ground rules for all of the above
- **Never fabricate data.** Only surface real fields from stremio-core / Supabase / the addon catalogs. If a mockup detail (e.g. a "4K HDR" badge) has no real backing data, say so rather than hardcoding a fake value — this was already the right call made earlier this session for exactly that badge.
- **Verify everything live.** Reading code and assuming it's fixed is not enough — load the real page with Playwright + a real browser binary (`/opt/brave-bin/brave` via `chromium.launch({ executablePath: ... })` — plain `npx playwright install`'s bundled Chromium has had version mismatches in this sandbox before) and confirm visually, ideally signed in with a real account (empty/anonymous state hides a lot of real bugs).
- **Watch for concurrent edits.** Other sessions have been editing this same repo concurrently (e.g. `iconMap.ts`, `Search.js` changed mid-session, unrelated to this work) — re-read files fresh before editing rather than trusting stale context, and don't revert changes that look deliberate just because you didn't make them.
- **Dev server discipline**: `fuser -k 8080/tcp` before restarting `pnpm start` — never leave two instances running (a past incident here caused a real OOM that killed the user's other apps).
- **Commit as you go**, small and focused, matching this session's established pattern.
