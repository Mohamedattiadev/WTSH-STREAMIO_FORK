What's here: a full redesigned shell (rail + top bar) over real Stremio pages — Board, Discover, Library, Chat ("Ask WTS"), Calendar, Addons, Settings, Search, and now a Player screen too. Click any Play/Resume button anywhere to open it, with a back arrow to return to where you were. Use the Desktop / iPad / Phone buttons above the preview (or drag its corner) to test the real responsive layout, not a separate mockup.

Fixed this round — the root cause of "buttons outside the card" and "wrapped text": rows holding multiple buttons (hero actions, preview-panel actions, addon actions) had no flex-wrap, so at narrow widths the browser's default behavior was to shrink each button below its content size — which made icon+text wrap onto two lines internally, and pushed the overflow past the card's rounded edge where an overflow:hidden ancestor silently clipped it (invisible, not just ugly). Every button row now wraps as whole buttons instead, and every button itself is pinned to white-space:nowrap — so buttons never split internally and never spill past a card again, in any mode.

Also this round: the trailer modal now opens as a proper video thumbnail (play ring, caption, duration badge) instead of a static icon block. "More Info" now opens that same modal with the title's real synopsis/genre/rating — answering what it's supposed to do. Calendar's "Upcoming" list is a real announcements feed (poster thumbnail + rating + trailer button per entry). Every addon now shows the site it's fetched from. Settings' section tabs scroll horizontally on phone (matching the Addon Hub strip) instead of wrapping to a second row. Chat's replies now include a plain-text-only example (proving it isn't locked to movie cards), plus a suggestion-chip row and an attach button above the composer.

Latest round — chat can actually schedule things now: the main Chat composer is a real, working input — type something like "I'll watch Low Tide this Friday" and send it. The assistant recognizes a title + a day, adds a real entry to Calendar's Upcoming list, lights up the matching day cell, and fires a notification — try it in the live demo (there's already one example pre-loaded, for Friday). This works in the floating chat popup too. A real notification center now sits behind the bell — click it for a dropdown with a few seeded alerts plus anything the chat schedules, a numbered unread badge, and "Mark all read". The Trailer button moved back to the center of the poster with a visible "Trailer" label (clearer than an icon-only corner button), and the trailer modal gained a "+ Library" action. Removed the redundant "More Info" button next to Trailer on the Board hero. The Player got real upgrades: Up Next now floats over the video itself so you never scroll to see it, skip ±10s buttons flank the big center play control, playback speed and quality are cyclable chips, plus subtitles/audio/PiP/fullscreen and a download button, and the info panel below now matches the app's rating/tag styling.
